# آهن‌چی – Flutter App

اپلیکیشن مشترک مدیر و نماینده برای ثبت و گزارش خرید ضایعات فلزی.

## امکانات نسخه اول

- رابط فارسی و راست‌به‌چپ
- ورود مدیر و نماینده با شماره موبایل
- ثبت فروشنده
- ثبت وزن به کیلوگرم با دقت گرم
- محاسبه خودکار مبلغ بر اساس قیمت هر کیلو به تومان
- ثبت پرداخت به فروشنده و دریافت از فروشنده
- SQLite محلی و کارکرد آفلاین
- همگام‌سازی خودکار با Workmanager و همگام‌سازی هنگام بازگشت به برنامه
- عملیات idempotent برای جلوگیری از ثبت تکراری
- داشبورد مدیریتی، تفکیک مواد، بدهی‌ها و عملکرد نمایندگان
- تم صنعتی ذغالی، مسی و سبز بازیافت

## پیش‌نیاز

- Flutter Stable با Dart 3.8 یا جدیدتر
- Android SDK و Java 17
- بک‌اند `Ahanchi-BE`

## آماده‌سازی و اجرا

اگر Wrapper یا فایل‌های تولیدی Android در Checkout تازه وجود ندارند، ابتدا اجرا کنید:

```bash
flutter create --platforms=android --org ir.ahanchi .
```

سپس:

```bash
flutter pub get
flutter test
flutter run
```

در صفحه ورود، آدرس API قابل تنظیم است. برای Emulator اندروید و بک‌اند روی همان کامپیوتر:

```text
http://10.0.2.2:3000/api/v1
```

برای گوشی واقعی باید IP یا دامنه HTTPS سرور وارد شود.

## ساخت APK

```bash
flutter build apk --release
```

پیش از انتشار عمومی، Keystore اختصاصی ایجاد و `signingConfig` نسخه Release جایگزین تنظیم موقت Debug شود.

## معماری آفلاین

فروشنده‌ها، خریدها و تراکنش‌های مالی ابتدا با UUID در SQLite ثبت می‌شوند. هنگام اتصال، ترتیب ارسال چنین است:

1. فروشنده‌های جدید
2. خریدها
3. عملیات مالی
4. دریافت فهرست به‌روز مواد

سرور UUID هر عملیات را یکتا نگه می‌دارد تا تکرار درخواست باعث ثبت دوباره نشود.
